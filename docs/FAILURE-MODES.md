# Failure Modes

The contract rejects zero-value policies, duplicate policies, invalid recipients, duplicate recipients, invalid basis-point totals, zero shares, invalid deadlines, wrong states, wrong owners, incorrect funding, unverified or replayed proofs, unauthorized results, stale results, malformed arrays, participant substitution, total mismatches, replayed nonces, duplicate settlement, failed transfers, and invalid refund attempts.

The frontend exposes wallet rejection, wrong network, insufficient C2FLR, RPC failure, timeout, reverted transaction, unavailable FDC/FCC/FTSO services, pending proof, expired policy, and settled terminal states without fabricating success.
